# Changelog

All notable changes to the Logseq GTD Template System will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.1.0] - 2026-01-27

### Added
- **Complete testing framework** with 100+ test items verified
- **Cross-platform validation** for Desktop, iOS, and Android
- **Performance benchmarks** documented for mobile optimization
- **GTD methodology compliance** verification across all 5 phases
- **Enhanced documentation** with actual test dates and results

### Changed
- **Updated TESTING_CHECKLIST.md** with comprehensive test results
- **Enhanced PACKAGE_SUMMARY.md** with testing completion status
- **Improved README.md** with testing verification details
- **Cleaned up directory structure** (removed empty Phase3/Phase4 directories)

### Fixed
- **Date references** updated from 2025 to 2026 throughout templates
- **Template validation** completed for all 24 template files
- **Cross-platform compatibility** documentation verified

## [1.0.0] - 2026-01-26

### Added
- **Complete GTD template system** with 15 comprehensive templates
- **Organized by GTD workflow phase**: Capture, Process, Organize, Review, Engage, Improve, System
- **Starter Kit** with 5 essential templates for beginners
- **Centralized query library** with 46 reusable components
- **Mobile-first design** optimized for touch interfaces
- **Integrated FAQ coverage** for common GTD questions

### Features
- **Plugin-free architecture** using only native Logseq features
- **Intelligent task selection** with context, priority, time, and energy awareness
- **Customizable settings** (next actions: 3-10, priority thresholds, contexts)
- **Guided GTD approach** with warnings instead of strict enforcement
- **Cross-platform compatibility** for Desktop and Mobile Logseq

### Documentation
- **Complete installation guide** with step-by-step instructions
- **Comprehensive usage guide** with workflow examples
- **Testing framework** for validation and troubleshooting
- **Package summary** with technical specifications

## [0.9.0] - 2025-12-15

### Added
- Initial template system with basic GTD implementation
- Core templates for capture, processing, and organization
- Basic documentation structure
- Query examples and research materials

## Release Notes

### Versioning Scheme
- **Major version (1.x.x)**: Breaking changes or major feature additions
- **Minor version (x.1.x)**: New features or significant enhancements
- **Patch version (x.x.1)**: Bug fixes and minor improvements

### Compatibility
- **Logseq Desktop**: v0.9.0+ recommended
- **Logseq Mobile**: iOS 14+, Android 10+
- **Platforms**: Windows, macOS, Linux, iOS, Android
