# Logseq GTD Starter Kit

## 🚀 Get Started in 30 Minutes

This starter kit contains the 5 essential templates you need to begin implementing GTD in Logseq. Start here if you're new to GTD or want a simplified approach.

## 📦 What's Included

### **Core 5 Templates:**
1. **[Quick Capture](../Capture/01-quick-capture.md)** - Capture thoughts instantly
2. **[Daily Journal](../Review/05-gtd-daily-journal.md)** - Plan your day
3. **[2-Minute Rule](../Process/09-2-minute-rule.md)** - Make quick decisions
4. **[Priority System](../Organize/03-basic-priority-system.md)** - Organize by importance
5. **[Weekly Review](../Review/08-weekly-review.md)** - Maintain your system

## 🎯 Why These 5 Templates?

These templates cover the essential GTD workflow without overwhelming you:

1. **Capture** everything that has your attention
2. **Process** quick decisions immediately
3. **Organize** by priority
4. **Review** daily and weekly
5. **Engage** with clear priorities

## 📋 Installation

### **Option 1: Quick Copy (Recommended)**
```bash
# Copy just the starter kit templates
cp GTD_Templates/Starter_Kit/*.md /path/to/your/logseq/graph/templates/
```

### **Option 2: Manual Setup**
1. Copy these 5 files to your Logseq templates directory:
   - `01-quick-capture.md`
   - `05-gtd-daily-journal.md`
   - `09-2-minute-rule.md`
   - `03-basic-priority-system.md`
   - `08-weekly-review.md`
2. Restart Logseq if templates don't appear immediately

## 🔄 Daily Workflow (10 Minutes)

### **Morning (5 minutes):**
1. Open **Daily Journal** template
2. Review priority tasks
3. Set focus for the day

### **Throughout Day:**
1. Use **Quick Capture** for any thought
2. Apply **2-Minute Rule** to quick tasks
3. Assign **Priorities** to captured items

### **Evening (5 minutes):**
1. Process captured items
2. Update task status
3. Prepare for tomorrow

## 📅 Weekly Workflow (30 Minutes)

### **Friday Afternoon:**
1. Use **Weekly Review** template
2. Process all inbox items
3. Review completed tasks
4. Plan next week's priorities
5. Clean up and organize

## 🎯 First Week Plan

### **Day 1: Setup & Capture**
- Install the 5 templates
- Capture everything on your mind using Quick Capture
- Don't process yet - just capture

### **Day 2: Daily Planning**
- Try the Daily Journal template
- Review yesterday's captures
- Plan today's 3 most important tasks

### **Day 3: Quick Decisions**
- Use the 2-Minute Rule template
- Process quick tasks immediately
- Experience inbox zero

### **Day 4: Prioritization**
- Apply the Priority System
- Categorize tasks as HIGH/MEDIUM/LOW
- Focus on HIGH priority items

### **Day 5: Weekly Review**
- Complete your first weekly review
- Process all accumulated items
- Plan for next week

## 💡 Pro Tips for Beginners

### **Start Small**
- Use only these 5 templates for the first month
- Don't try to implement everything at once
- Focus on consistency over perfection

### **Build Habits**
- Daily journal every morning
- Quick capture throughout day
- Weekly review every Friday
- 2-minute rule for instant decisions

### **Customize Gradually**
- After 2 weeks, adjust template settings
- After 1 month, consider adding more templates
- Always maintain the core 5 workflow

## 🚨 Common Beginner Mistakes

### **❌ Trying to use all 16 templates at once**
**Solution:** Start with these 5, add gradually

### **❌ Skipping weekly reviews**
**Solution:** Schedule Friday afternoon, non-negotiable

### **❌ Not using quick capture**
**Solution:** Make it your default for any thought

### **❌ Overcomplicating priorities**
**Solution:** Use simple HIGH/MEDIUM/LOW, not complex systems

### **❌ Avoiding the 2-minute rule**
**Solution:** Do quick tasks immediately, build the habit

## 🔍 Troubleshooting

### **Templates not appearing?**
1. Check templates are in correct directory
2. Restart Logseq
3. Verify file permissions

### **Overwhelmed by captures?**
1. Schedule daily processing time
2. Use 2-minute rule more aggressively
3. Don't capture during focused work

### **Weekly review taking too long?**
1. Limit to 30 minutes maximum
2. Focus on key areas only
3. Defer complex processing to next day

### **Not seeing benefits?**
1. Give it 2 weeks minimum
2. Focus on habit formation
3. Adjust templates to your workflow
