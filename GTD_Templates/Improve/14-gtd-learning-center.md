## 📚 GTD Fundamentals

### Core GTD Principles
```markdown
## The Five Stages of GTD
### 1. CAPTURE
**Goal:** Get everything out of your head
**Tools:** [[GTD Quick Capture]], [[GTD Integration Hub]]
**Best Practice:** Capture anything that has your attention

### 2. CLARIFY  
**Goal:** Decide what each item means
**Tools:** [[GTD Task Processing]], [[2-Minute Rule]]
**Best Practice:** Is it actionable? If yes, what's the next action?

### 3. ORGANIZE
**Goal:** Put items where they belong
**Tools:** [[GTD Management Dashboard]], [[GTD Next Actions Dashboard]]
**Best Practice:** Right place for right item

### 4. REFLECT
**Goal:** Review frequently
**Tools:** [[GTD Daily Journal]], [[GTD Weekly Review]]
**Best Practice:** Weekly review is non-negotiable

### 5. ENGAGE
**Goal:** Do the work
**Tools:** Context, time, energy, priority filtering
**Best Practice:** Trust your system, choose based on situation
```

### Key GTD Concepts Explained

#### Mind Like Water
**Concept:** Your mind should be like water - responsive and appropriate  
**Achieved by:** Complete, trusted external system  
**Result:** Reduced stress, increased focus

#### Next Action Principle
**Rule:** Every project must have a defined next action  
**Quality:** Specific, physical, visible activity  
**Example:** "Draft introduction section" not "Work on report"

#### 2-Minute Rule  
**Rule:** If it takes less than 2 minutes, do it now  
**Purpose:** Prevent system clutter  
**Implementation:** [[2-Minute Rule Template]]

#### Weekly Review
**Critical practice:** Engine that makes GTD work  
**Frequency:** Non-negotiable weekly commitment  
**Template:** [[GTD Weekly Review]]

## ❓ GTD FAQs & Troubleshooting

### Common GTD Questions

#### "How do I get started with GTD?"
**Step-by-step guide:**
1. **Week 1:** Set up [[GTD Quick Capture]] and capture everything
2. **Week 2:** Learn [[GTD Task Processing]] and clarify items
3. **Week 3:** Organize with [[GTD Management Dashboard]]
4. **Week 4:** Establish [[GTD Weekly Review]] habit
5. **Month 2:** Refine with [[GTD Analytics & Improvement]]

#### "My inbox is always overflowing"
**Solutions:**
- Schedule daily processing time
- Use [[2-Minute Rule]] for quick items
- Set boundaries on new captures
- Review [[GTD Integration Hub]] for automation

#### "I don't know what to work on next"
**Solutions:**
- Check [[GTD Daily Journal]] for context-based suggestions
- Use [[GTD Next Actions Dashboard]] filtering
- Apply GTD's four criteria: context, time, energy, priority
- Trust your system during [[GTD Weekly Review]]

#### "Projects never seem to move forward"
**Solutions:**
- Ensure every project has a next action ([[Project-Next Action Enforcement]])
- Break down projects into smaller actions
- Review during [[GTD Weekly Review]]
- Track progress with [[GTD Analytics & Improvement]]

#### "I keep forgetting the weekly review"
**Solutions:**
- Schedule it like any other appointment
- Use reminders in [[GTD Weekly Review]] template
- Start with 30-minute reviews, build up
- Make it enjoyable with your favorite beverage/music

### Troubleshooting Guide

#### System Not Working
**Symptoms:** Stress increasing, things falling through cracks  
**Diagnosis:** Likely incomplete capture or missed reviews  
**Treatment:** Return to basics, complete [[GTD Weekly Review]]

#### Too Much Maintenance
**Symptoms:** Spending more time managing system than doing work  
**Diagnosis:** Over-engineering or wrong tools  
**Treatment:** Simplify, use templates, automate with [[GTD Integration Hub]]

#### Lack of Trust
**Symptoms:** Double-checking system, mental reminders  
**Diagnosis:** Incomplete system or inconsistent use  
**Treatment:** Complete [[GTD Weekly Review]], test system reliability

#### Mobile Challenges
**Symptoms:** Different experience on mobile vs desktop  
**Diagnosis:** Platform optimization needed  
**Treatment:** Use mobile-optimized templates, [[Cross-Platform Test]]
